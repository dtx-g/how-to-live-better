# 高性价比人生指南 · 在线阅读页

这是一个自制的单文件 HTML 阅读网站，把 PDF《高性价比人生指南》的正文整理成可点击、可搜索的网页。手机或电脑打开网页即可阅读，不需要安装任何软件。

## 在线阅读

**[打开网站](https://dtx-g.github.io/how-to-live-better/)**

## 页面特性

- **章节索引**：左侧按主题浏览 34 个章节，也可以展开章节查看条目。
- **全文搜索**：输入关键词，实时筛选建议、解释和来源。
- **多条件筛选**：按适用人群、证据等级、花钱、花时间、毅力和收益口径筛选。
- **可点击跳转**：正文里的章节引用和条目编号可以直接打开对应内容。
- **手机适配**：小屏幕上自动收起索引，搜索和阅读仍然可用。
- **单文件加载**：正文已经嵌入首页 HTML，打开后不需要再加载 34 个 Markdown 文件。
