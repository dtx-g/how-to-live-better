# 网站说明

这是用户提供的《高性价比人生指南》PDF 的可检索网页版本。

## 主要功能

- 34 个主题章节、690 条建议全文检索
- 按适用人群、章节、证据等级和成本筛选
- 移动端布局与深色模式
- 保留每条建议的成本、收益、证据等级和来源
- 提供独立项目说明页和原始版本链接

## 本地预览

在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。
